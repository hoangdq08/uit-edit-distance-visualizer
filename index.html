Khoảng cách chỉnh sửa (Edit Distance / Levenshtein)

Số thao tác thêm, xóa, thay một ký tự ít nhất để biến chuỗi A thành chuỗi B. Quy hoạch động O(n·m).

→

1. Khởi tạo2. Điền bảng3. Truy vết
Ô đang tính ↖ thay ↑ xóa ← thêm nguồn được chọn (đậm) đường truy vết

Bước hiện tại

Mã giả (dòng đang thực hiện được tô sáng)

    Kết quả

      Mô hình bài toán

      Input

      • A: chuỗi nguồn, độ dài n
      • B: chuỗi đích, độ dài m
      • Ký tự thuộc A..Z. Giới hạn đề (Wecode): 1 ≤ n, m ≤ 5000. Demo: 0 ≤ n, m ≤ 20

      Output

      • d: số nguyên, số thao tác thêm / xóa / thay ít nhất để biến A thành B
      • Demo in thêm một dãy thao tác cụ thể đạt đúng d bước

      Công thức truy hồi

      dp[i][0] = i          dp[0][j] = j
A[i] = B[j]:  dp[i][j] = dp[i-1][j-1]
ngược lại:    dp[i][j] = 1 + min( dp[i-1][j-1]  (thay),
                                  dp[i-1][j]    (xóa A[i]),
                                  dp[i][j-1]    (thêm B[j]) )
đáp án:       d = dp[n][m]

      dp[i][j] là số thao tác ít nhất để biến A[1..i] thành B[1..j]. Độ phức tạp thời gian O(n·m), bộ nhớ O(n·m) (giữ bảng để truy vết) hoặc O(m) (chỉ tính d).
